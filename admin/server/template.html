访问令牌

每条令牌属于一个操作人：登录后用它的写操作都会记下「谁干的」（操作日志页的「操作人」列）。 令牌只存 sha256，明文只在创建时显示这一次，过后找不回来。

表里一条都没有时，/api/* 对白名单内的来源完全开放（启动日志会警告）； 有令牌但全被停用则会拒绝所有人 —— 那种情况只能靠 papa token add 补一把。

报告列表
