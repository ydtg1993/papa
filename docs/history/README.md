# 历史材料导航

<!-- version-scope -->
> 适用版本：Papa v4 演进历史及当次工作区验证。此目录只在框架源码仓库保留，不随 `papa new/upgrade` 分发；当前契约从 [使用手册](../README.md) 进入。
<!-- /version-scope -->

| 目录/文件 | 用途 |
| --- | --- |
| [审查与验证](reviews/README.md) | 问题证据、修复批次、测试环境与限制，以及阶段框架画像 |
| [设计](designs/README.md) | 曾提出或批准的方案；明确待实施、已实施或已替代状态 |
| [实施计划](plans/README.md) | 当次施工步骤和验证安排；计划不是已经完成的证据 |
| [历史变更记录](changes.md) | 按原条目保留症状、修法与验证，不当作当前能力清单 |

新材料继续使用日期和主题命名，首部注明版本/阶段、代码基线（已知时）、状态和当前手册入口。当前 API/配置用法只维护在各使用手册；包职责只维护在 `package_structure/`。不要从历史材料回填已取消的 SQL Trace、手动追踪或旧版本兼容方案。
