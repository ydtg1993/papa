用户已批准施工。沿用独立设计文档，混合错误遵循正文的“先观察、分析，再决定暂停”。

1. 实现终态任务轮次去重、稳定错误指纹、短窗同类快速保护、混合观察及长窗失败数保底。
2. 限流交给现有治理控制器：检查 AutoThrottle 开关；明确 Retry-After 始终尊重。
3. 接入引擎的观察、冷却、只读探测、限量恢复和人工处理状态；保存事件及恢复预算，启动先恢复闸门。
4. 保存有界、脱敏的事件报告并接入现有后台分析入口；人工操作不被自动恢复覆盖。
5. 使用合成错误/页面、假时钟、隔离数据库验证，并同步配置与运行手册。仅改工作区，不进行 Git 写操作。
