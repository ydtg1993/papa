用户已要求增加此前预留的主动追踪按钮与流程；保留现有改动，不执行 Git 写操作。

目标：任务行更多菜单登记/取消下一执行追踪，追踪详情显示待生效申请。登记不重投、不加急；正在执行时只作用于下一次成功认领；同轮所有重试保留，一小时有效，重启失效。取消只移除尚未消费的申请，不中断执行。

职责：engine/trace_service.go 拥有选择与锁；core 新增只读选择快照；admin/tasksource 声明动作并沿用 oao 鉴权审计；admin/tasktrace 读取及显示状态；server/App 只装配回调。不修改旧 TaskActions、Options、MonitorConfig 的布局或必需方法。
