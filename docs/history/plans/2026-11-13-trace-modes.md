用户决定取消后台主动按钮。采用启动配置 crawler.trace.mode=off/errors/all，默认 errors。

1. config 拥有模式值、默认值、旧 YAML enabled 兼容；非法值拒绝启动。
2. Engine 删除手动选择状态/锁/context 消费；尝试缓冲按 errors/all 决定保留，off 不创建。
3. 保持文件存储预算、取消语义及七天保留；全量空尝试补完成标记。
4. 后台只保留查看入口，更新模板、配置/结构手册及诊断记录。
5. 补模式、旧配置、重试、取消与空尝试回归；运行全量 test/race、vet、build、脚手架构建。不执行 Git 写操作。
